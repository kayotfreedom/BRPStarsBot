# Telegram-бот «Звёзды и Рефералы» (BRPStars)

Telegram-бот на базе aiogram (v3), предназначенный для заработка внутренней валюты («звёзд») через реферальную систему, выполнения заданий и активации промокодов. Включает в себя полноценную админ-панель для управления пользователями, рассылками и контентом.

> Важное примечание: Основой для данного проекта послужил сторонний скелет бота (шаблон). Текущая версия была адаптирована, дополнена и настроена под конкретные задачи. Исходный код скелета был взят из открытого источника/репозитория и переработан.

## 🚀 Основной функционал

### Для пользователей:
- Регистрация и реферальная система: Генерация персональной ссылки, начисление звёзд за приглашённых друзей (+3 ⭐️ за друга).
- Личный кабинет: Просмотр баланса звёзд, количества приглашённых рефералов и выведенных средств.
- Вывод звёзд: Создание заявки на вывод (доступно при наличии минимум 5 рефералов). Уведомление администраторов о запросе.
- Задания: Раздел для выполнения заданий (в текущей версии — заглушка, но база данных и методы для заданий уже готовы).
- Промокоды: Возможность активации промокодов для получения звёзд.
- Помощь: Раздел с ответами на частые вопросы (не засчитали реферала, не вывелись звёзды) и ссылкой на поддержку.
- Обязательная подписка: Проверка подписки на указанные каналы перед доступом к основному функционалу.

### Для администраторов:
- Управление звёздами: Ручное начисление и списание звёзд пользователям по ID.
- Рассылки: Отправка сообщений всем пользователям или отдельно тем, кто не пригласил ни одного реферала.
- Управление каналами: Добавление и удаление ID каналов для обязательной подписки.
- Управление промокодами: Создание новых промокодов (количество звёзд и лимит использований) и деактивация существующих.
- Бэкап базы данных: Отправка файла database.db администратору прямо в Telegram.
- Статистика: Просмотр общего количества пользователей и суммы выведенных звёзд.

## 📂 Структура проекта

├── main.py          # Основной файл бота (роутеры, хэндлеры, FSM)

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
Убедитесь, что у вас установлен Python 3.10 или выше.

pip install aiogram

### 2. Настройка settings.py
Откройте файл settings.py и укажите свои данные:

- TOKEN — токен вашего бота (получить у @BotFather).
- channel_ids — список ID каналов (в формате -100...), на которые должна быть оформлена подписка.
- admins — список Telegram ID пользователей, которые получат доступ к админ-панели.

TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
channel_ids = [-1001234567890]
admins = [123456789]

### 3. Инициализация базы данных
При первом запуске бота файл database.db создастся автоматически (если его нет), и в нём появятся нужные таблицы (users, promocodes, promocode_uses, tasks).

### 4. Запуск бота

python main.py

## ⚙️ Технические детали

- Библиотека: aiogram версии 3.x.
- База данных: SQLite (встроенная, не требует отдельного сервера).
- Состояния (FSM): Используются для пошагового ввода данных администратором (добавление звёзд, промокодов, рассылки и т.д.).
- Клавиатуры: ReplyKeyboardBuilder для главного меню и InlineKeyboardBuilder для интерактивных действий.

## ⚠️ Известные особенности
- В коде реализована проверка подписки на каналы. Убедитесь, что бот является администратором в этих каналах, иначе проверка может не работать.
- Для работы функции «Бэкап БД» убедитесь, что у бота есть доступ к файлу database.db в рабочей директории.
- В текущей версии раздел «Задания» выводит заглушку, но в database.py уже есть функции для отслеживания выполнения заданий (таблица tasks).
